# 🌊🔥 Blender Physics Simulations: Quick Liquid, Smoke & Fur

A practice project in **Blender** showcasing dynamic physical effects and particle systems.

## 🎬 Scene Overview
This project integrates three core dynamic simulations:
1. 

**Quick Liquid**: A suspended water sphere that impacts the domain, creating realistic splashing behaviour.
2. 

**Quick Smoke**: Volumetric smoke simulation emitting from a cone.
3. 

**Quick Fur**: Dynamic particle grooming applied to the Suzanne mesh.

## 📂 Repository Contents
- `quick_effects_showcase.blend` — The complete project file.



## 🚀 Usage
Open the `.blend` file in Blender and press Space to play the simulation.
